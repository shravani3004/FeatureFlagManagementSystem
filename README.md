# Feature Flag Management System

## Overview
Feature Flag Management System is a Java web application that enables administrators to manage application features dynamically.

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- HTML
- CSS

## Features
- Admin Login
- Add Feature Flags
- Edit Feature Flags
- Delete Feature Flags
- Enable/Disable Feature Flags
- Environment Support (DEV, STAGING, PROD)
- MySQL Database Integration
